# Security reports

For a suspected vulnerability, contact the maintainer through a contact method listed on the [GitHub profile](https://github.com/KljajicS). If no private contact method is listed, open an [issue](https://github.com/KljajicS/kinjar/issues) requesting a private reporting channel without describing the vulnerability. A private reporting channel is not currently documented.

Do not post credentials, signing keys, account identifiers, financial records, backups or exploit details in public issues. Use synthetic data for reproduction steps. Once a private channel is agreed, include the affected version, Android version, expected behavior, observed behavior and minimal reproduction.

See [security design and limits](docs/security.md) for app lock, local storage, cloud access and backup behavior. Sync remains experimental. There is no published support schedule for older releases; fixes target the current version. Preserve a verified backup and install compatible updates without uninstalling the app.
